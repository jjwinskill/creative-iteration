# Well ledger

Answers models keep reaching for, by kind of brief. This is about model habits, not the person, so it doesn't break the rule that agents learn about the person only from the brief.

A well goes here when it shows up in two or more runs, or when one run marks it a well (both cold answers, or the unprompted lists of 3 or more agents). After each run, add new wells, and bump the count when a well shows up again. Wells are kept, never deleted: they reach the menu through the convergent lane.
